# 图像分类微调计划

## 两套方案

- A1：冻结骨干网络，只训练最后的分类头（快，显存小）
- A2：全部参数一起微调（慢，显存大）

## 实验

| 代号 | 方案 | 改动 |
|---|---|---|
| E1 | A1 | 基线：ResNet-50，学习率 1e-3 |
| E2 | A1 | E1 + 数据增强（随机裁剪、水平翻转） |
| E3 | A2 | 基线：全量微调，学习率 1e-4 |
| E4 | A2 | E3 + 数据增强 |
| E5 | A2 | E4 + 学习率减半（5e-5） |

## 判断标准

验证集 top-1 准确率高的赢；两组差不到 0.5 个点时，选训练时间短的那组。
